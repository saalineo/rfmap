# RFMap documentation

This directory explains how RFMap is intended to work before a developer changes it.

| Document | Read it when you need to… |
|---|---|
| [Architecture](ARCHITECTURE.md) | understand the product, data flow, boundaries, and package ownership |
| [Development](DEVELOPMENT.md) | install dependencies, run the app/tests, or add a feature |

Package-level READMEs sit next to the code they describe. They document the APIs and rules that are most likely to matter while editing that package.
